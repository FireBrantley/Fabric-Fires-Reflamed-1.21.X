# Blocks

Fire's Reflamed adds a variety of functional and decorative blocks, including storage blocks for each material, decorative Ruby and Snow Brick sets with stair/slab/wall variants, and Steel utility blocks.

---

## Storage Blocks

Each material can be compacted into a storage block using 9 of its primary material in a 3×3 crafting grid. All storage blocks can be broken back down into 9 units.

- [](@firesreflamed:block_of_titanium) — Stores 9 [](@firesreflamed:titanium_ingot)s. Also required for the [](@firesreflamed:titanium_bat).
- [](@firesreflamed:block_of_steel) — Stores 9 [](@firesreflamed:steel_ingot)s. Also required for the [](@firesreflamed:steel_bat).
- [](@firesreflamed:block_of_ruby) — Stores 9 [](@firesreflamed:ruby_gem)s. Also required for the [](@firesreflamed:ruby_bat) and all Ruby decorative blocks.
- [](@firesreflamed:block_of_aquamarine) — Stores 9 [](@firesreflamed:aquamarine_shard)s.

---

## Ruby Decorative Blocks

A set of decorative blocks derived from [](@firesreflamed:block_of_ruby). All variants can be crafted from [](@firesreflamed:ruby_bricks) or cut directly from [](@firesreflamed:block_of_ruby) using a stonecutter.

- [](@firesreflamed:ruby_bricks) — Base decorative block, crafted from 4 Blocks of Ruby in a 2×2 pattern
- [](@firesreflamed:ruby_stairs) — Stair variant
- [](@firesreflamed:ruby_slab) — Slab variant
- [](@firesreflamed:ruby_wall) — Wall variant
- [](@firesreflamed:ruby_cluster) — Light-emitting decorative block (light level 7), crafted from Ruby Gems

---

## Steel Utility Blocks

Decorative and functional blocks crafted from [](@firesreflamed:steel_ingot) and [](@firesreflamed:steel_nugget).

- [](@firesreflamed:steel_chain) — Decorative chain block, identical in function to vanilla Chain
- [](@firesreflamed:steel_lantern) — Light-emitting lantern (light level 15), pairs naturally with Steel Chain
- [](@firesreflamed:steel_bars) — Iron Bar equivalent, crafted from Steel Ingots

---

## Snow Brick Blocks

A snow-themed decorative set crafted from vanilla Snow Blocks. These blocks make up the [](@firesreflamed:snow_brick_igloo) structure.

- [](@firesreflamed:snow_bricks) — Base block, crafted from 4 Snow Blocks in a 2×2 pattern
- [](@firesreflamed:snow_brick_stairs) — Stair variant
- [](@firesreflamed:snow_brick_slab) — Slab variant
- [](@firesreflamed:snow_brick_wall) — Wall variant
