# Blocks

Fire's Reflamed adds a variety of new blocks, including ore blocks, storage blocks, and decorative sets.

---

## Storage Blocks

These 3×3 compacting blocks store 9 of their respective material.

| Block | Material | Hardness | Tool Required | Sounds |
|---|---|---|---|---|
| Block of Titanium | Titanium Ingot | 3.0 | Pickaxe | Netherite |
| Block of Steel | Steel Ingot | 5.0 | Pickaxe | Metal |
| Block of Ruby | Ruby Gem | 4.0 | Pickaxe | Amethyst Block |
| Block of Aquamarine | Aquamarine Shard | 4.0 | Pickaxe | Amethyst Block |

All follow the vanilla 3×3 crafting pattern (or can be broken back down into 9 items).

## Ruby Decorative Blocks

Ruby Gems can be used to craft a set of decorative building blocks.

| Block | Hardness | Sounds | Recipe |
|---|---|---|---|
| Ruby Bricks | 4.0 | Amethyst | 2×2 Block of Ruby → 4 Ruby Bricks |
| Ruby Brick Stairs | 4.0 | Amethyst | Standard stair recipe from Ruby Bricks |
| Ruby Brick Slab | 4.0 | Amethyst | Standard slab recipe from Ruby Bricks |
| Ruby Brick Wall | 4.0 | Amethyst | `RRR / RRR` (6 Ruby Bricks → 6 walls) |
| Ruby Cluster | 1.0 | Amethyst Cluster | ` R ` / `RRR` (3 Ruby Gems) |

**Stonecutter support:** Block of Ruby and Ruby Bricks can be stonecutter-converted to any ruby building block variant.

**Ruby Cluster** emits a light level of 7 and is non-opaque. It behaves similarly to an amethyst cluster.

## Snow Decorative Blocks

A new set of snow-themed building blocks crafted from Snow Blocks.

| Block | Hardness | Sounds | Recipe |
|---|---|---|---|
| Snow Bricks | 0.5 | Snow | 2×2 Snow Blocks → 4 Snow Bricks |
| Snow Brick Stairs | 0.5 | Snow | Standard stair recipe from Snow Bricks |
| Snow Brick Slab | 0.5 | Snow | Standard slab recipe from Snow Bricks |
| Snow Brick Wall | 0.5 | Snow | `SSS / SSS` (6 Snow Bricks → 6 walls) |

**Stonecutter support:** Snow Blocks and Snow Bricks can be stonecutter-converted to any snow brick variant.

> Snow brick blocks require a tool to mine (pickaxe or shovel recommended).
