# Ruby Bat

The Ruby Bat is a mid-tier bat weapon crafted from [](@firesreflamed:block_of_ruby). It has a neutral damage modifier and slightly better attack speed than the [](@firesreflamed:steel_bat).

<PrefabObtaining />

## Stats

| Property | Value |
|---|---|
| Base Damage Modifier | +0 |
| Attack Speed | Medium (-2.7) |
| Durability | 650 |
| Enchantability | 14 |
| Repair Item | [](@firesreflamed:ruby_gem) |

> Final attack damage = Ruby material bonus (10) + bat modifier (0) + 1 = **11**.

## Notes

Bats are **not stackable** (max stack size: 1). Can be enchanted and repaired on an anvil with [](@firesreflamed:ruby_gem). See also: [](@firesreflamed:wooden_bat), [](@firesreflamed:steel_bat), [](@firesreflamed:titanium_bat).
