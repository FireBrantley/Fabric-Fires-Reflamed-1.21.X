# Wooden Bat

The Wooden Bat is an early-game melee weapon unique to Fire's Reflamed. It's slower than a sword but available immediately from the start of the game — no special materials required.

<PrefabObtaining />

## Stats

| Property | Value |
|---|---|
| Base Damage Modifier | +5 |
| Attack Speed | Slow (-2.9) |
| Repair Item | — |

> Final attack damage = tool material's base bonus + bat modifier (+5) + 1.

## Crafting

```
M M
MMM
_S_
```
- `M` = any Log block
- `S` = Stick

## Notes

Bats are **not stackable** (max stack size: 1). The Wooden Bat cannot be repaired on an anvil. Upgrade to a [](@firesreflamed:steel_bat), [](@firesreflamed:ruby_bat), or [](@firesreflamed:titanium_bat) as you progress through the material tiers.
