# Steel Sword

The Steel Sword is a mid-tier sword crafted from [](@firesreflamed:steel_ingot). It sits between Iron and Diamond in damage output.

<PrefabObtaining />

## Stats

| Property | Value |
|---|---|
| Attack Damage | 6.0 |
| Attack Speed | Fast (-2.4) |
| Durability | 750 |
| Enchantability | 14 |
| Repair Item | [](@firesreflamed:steel_ingot) |

> Attack damage = material bonus (10) + per-item bonus (-4) + base 1 = 6.

## Notes

Steel must be crafted — there is no Steel ore. See [](@firesreflamed:steel_ingot) for the full production chain. For a heavier hitting alternative at the same tier, consider the [](@firesreflamed:steel_bat).
