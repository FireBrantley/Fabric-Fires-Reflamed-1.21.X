# Titanium Bat

The Titanium Bat is the highest-tier bat weapon in Fire's Reflamed, crafted from [](@firesreflamed:block_of_titanium). It has medium attack speed and the best damage output of all bat variants.

<PrefabObtaining />

## Stats

| Property | Value |
|---|---|
| Base Damage Modifier | +2 |
| Attack Speed | Medium (-2.6) |
| Durability | 2,500 |
| Enchantability | 28 |
| Repair Item | [](@firesreflamed:titanium_ingot) |

> Final attack damage = Titanium material bonus (10) + bat modifier (+2) + 1 = **13**.

## Crafting

```
M M
MMM
_S_
```
- `M` = [](@firesreflamed:block_of_titanium)
- `S` = [](@firesreflamed:titanium_ingot)

## Notes

Bats are **not stackable** (max stack size: 1). The Titanium Bat can be enchanted and repaired on an anvil with [](@firesreflamed:titanium_ingot). For comparison across the bat lineup, see [](@firesreflamed:wooden_bat), [](@firesreflamed:steel_bat), and [](@firesreflamed:ruby_bat).
