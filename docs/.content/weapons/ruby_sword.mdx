# Ruby Sword

The Ruby Sword is a gem-tier sword crafted from [](@firesreflamed:ruby_gem). It has slightly less damage than the [](@firesreflamed:steel_sword) but good enchantability for its tier.

<PrefabObtaining />

## Stats

| Property | Value |
|---|---|
| Attack Damage | 5.0 |
| Attack Speed | Fast (-2.4) |
| Durability | 650 |
| Enchantability | 14 |
| Repair Item | [](@firesreflamed:ruby_gem) |

> Attack damage = material bonus (10) + per-item bonus (-5) + base 1 = 5.

## Notes

Ruby has no armor set, so the Ruby Sword and [](@firesreflamed:ruby_bat) are the primary combat uses for [](@firesreflamed:ruby_gem). Ruby Gems are obtained by refining [](@firesreflamed:ruby_crystal) from [](@firesreflamed:ruby_ore).
