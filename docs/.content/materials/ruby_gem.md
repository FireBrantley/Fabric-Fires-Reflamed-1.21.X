# Ruby Gem

Ruby is a gem material used for high-enchantability tools and decorative blocks.

## Obtaining

Rubies are found as **Ruby Ore**. Mining the ore drops **Ruby Crystals**, which can then be crafted into Ruby Gems.

- Craft 2 Ruby Crystals (vertically) → 1 **Ruby Gem**.
- Smelt Ruby Ore directly for Ruby Gems.

<PrefabObtaining />

### Generation

Ruby Ore generates in all Overworld biomes between Y levels **-16 and 64**.

## Usage

Used for crafting the Ruby tool set, Ruby Bat, and various decorative building blocks.
