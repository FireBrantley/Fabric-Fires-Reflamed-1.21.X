# Deepslate Ruby Ore

Deepslate Ruby Ore is the deep variant of [](@firesreflamed:ruby_ore), generating below Y 0 in deepslate layers. It drops [](@firesreflamed:ruby_crystals) when mined.

<PrefabObtaining />

## Generation

Generates below Y 0 in all Overworld biomes where [](@firesreflamed:ruby_ore) veins intersect deepslate.

## Mining

| Property | Value |
|---|---|
| Hardness | 4.5 |
| XP Drop | 3–7 |
| Sounds | Deepslate |
| Required Tool | Pickaxe |

## Processing

| Input | Output | XP | Time |
|---|---|---|---|
| Deepslate Ruby Ore | [](@firesreflamed:ruby_gem) | 1.0 | 300 ticks (furnace), 150 ticks (blast furnace) |
