# Aquamarine Ore

Aquamarine Ore is an ore block found in stone layers that drops [](@firesreflamed:aquamarine_shard) when mined. A deepslate variant, [](@firesreflamed:deepslate_aquamarine_ore), generates at deeper levels. Aquamarine is used exclusively for armor — it has no tool set.

<PrefabObtaining />

## Generation

Aquamarine Ore generates in all Overworld biomes between **Y -16 and Y 48** with a uniform distribution. Veins can be up to **7 blocks** in size, with approximately **14 attempts per chunk**.

## Mining

Mining Aquamarine Ore drops **Aquamarine Shards** directly — no smelting is required. Shards can be compacted into a [](@firesreflamed:block_of_aquamarine) (9 shards) or broken back down.

| Property | Value |
|---|---|
| Hardness | 4.0 |
| XP Drop | 3–7 |
| Sounds | Stone |
| Required Tool | Pickaxe |

## Smelting

Aquamarine Ore can also be smelted, yielding an additional XP bonus on the deepslate variant.

| Input | Output | XP | Time |
|---|---|---|---|
| Aquamarine Ore | Aquamarine Shard | 0.8 | 200 ticks (furnace), 100 ticks (blast furnace) |
| Deepslate Aquamarine Ore | Aquamarine Shard | 1.0 | 300 ticks (furnace), 150 ticks (blast furnace) |
