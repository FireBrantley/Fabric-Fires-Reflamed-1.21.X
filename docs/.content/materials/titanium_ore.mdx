# Titanium Ore

Titanium Ore is a stone-layer ore block that drops [](@firesreflamed:raw_titanium) when mined. A deepslate variant, [](@firesreflamed:deepslate_titanium_ore), generates in deeper layers.

<PrefabObtaining />

## Generation

Titanium Ore generates in all Overworld biomes between **Y -80 and Y 32** with a uniform distribution. Veins can be up to **10 blocks** in size, with approximately **12 attempts per chunk**.

## Mining

Mining Titanium Ore drops **Raw Titanium**, which can then be smelted into [](@firesreflamed:titanium_ingot). Using a Fortune enchantment does not increase the drop from this ore — it drops one Raw Titanium per block.

| Property | Value |
|---|---|
| Hardness | 3.0 |
| XP Drop | 2–5 |
| Sounds | Stone |
| Required Tool | Pickaxe |

## Processing

Smelt Raw Titanium or Titanium Ore in a furnace or blast furnace to obtain [](@firesreflamed:titanium_ingot).

| Input | Output | XP | Time |
|---|---|---|---|
| Raw Titanium / Titanium Ore | Titanium Ingot | 0.7 | 200 ticks (furnace), 100 ticks (blast furnace) |
| Deepslate Titanium Ore | Titanium Ingot | 0.7 | 300 ticks (furnace), 150 ticks (blast furnace) |
