# Aquamarine Shard

Aquamarine is a gem material used exclusively for armor.

## Obtaining

Aquamarine is obtained by mining **Aquamarine Ore** found in the Overworld.

<PrefabObtaining />

### Generation

Aquamarine Ore generates in all Overworld biomes between Y levels **-16 and 48**.

## Usage

Used to craft the Aquamarine armor set.
