# Ruby Ore

Ruby Ore is an ore block found in stone layers that drops [](@firesreflamed:ruby_crystal) when mined. A deepslate variant, [](@firesreflamed:deepslate_ruby_ore), generates at deeper levels.

<PrefabObtaining />

## Generation

Ruby Ore generates in all Overworld biomes between **Y -16 and Y 64** with a uniform distribution. Veins can be up to **8 blocks** in size, with approximately **14 attempts per chunk**.

## Mining

Mining Ruby Ore drops **Ruby Crystals**. Two Ruby Crystals crafted vertically yield one [](@firesreflamed:ruby_gem). Alternatively, you can smelt Ruby Ore directly to obtain Ruby Gems.

| Property | Value |
|---|---|
| Hardness | 4.0 |
| XP Drop | 3–7 |
| Sounds | Stone |
| Required Tool | Pickaxe |

## Processing

| Input | Output | XP | Time |
