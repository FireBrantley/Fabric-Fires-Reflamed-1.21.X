# Ruby Gem

The Ruby Gem is a refined gem material used for crafting Ruby-tier tools, weapons, and decorative blocks. It is obtained by processing [](@firesreflamed:ruby_crystal) from [](@firesreflamed:ruby_ore).

<PrefabObtaining />

## Obtaining

Craft two [](@firesreflamed:ruby_crystal)s vertically in a crafting grid to produce one Ruby Gem. You can also smelt [](@firesreflamed:ruby_ore) or [](@firesreflamed:deepslate_ruby_ore) directly in a furnace or blast furnace.

Compact 9 Ruby Gems into a [](@firesreflamed:block_of_ruby), or break it back down. Ruby is a tools-only material — there is no Ruby armor set.

## Uses

Ruby Gems are used to craft:

- [](@firesreflamed:ruby_pickaxe), [](@firesreflamed:ruby_shovel), [](@firesreflamed:ruby_axe), [](@firesreflamed:ruby_hoe)
- [](@firesreflamed:ruby_sword)
- [](@firesreflamed:ruby_bat)
- [](@firesreflamed:block_of_ruby) (9 gems)
- Ruby decorative blocks (via Block of Ruby)

Ruby Gems also serve as the **repair material** for all Ruby-tier tools and weapons.
