# Deepslate Titanium Ore

Deepslate Titanium Ore is the deep variant of [](@firesreflamed:titanium_ore), generating below Y 0 in deepslate layers. It drops [](@firesreflamed:raw_titanium) when mined and takes longer to break than its stone counterpart.

<PrefabObtaining />

## Generation

Deepslate Titanium Ore generates below Y 0 in all Overworld biomes, in the same veins as [](@firesreflamed:titanium_ore) where the vein intersects deepslate layers.

## Mining

| Property | Value |
|---|---|
| Hardness | 4.5 |
| XP Drop | 2–5 |
| Sounds | Deepslate |
| Required Tool | Pickaxe |
