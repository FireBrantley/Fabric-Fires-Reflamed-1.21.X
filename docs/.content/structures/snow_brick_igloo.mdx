# Snow Brick Igloo

The Snow Brick Igloo is a naturally generated structure added by Fire's Reflamed. It is a variant of the vanilla Igloo built from [](@firesreflamed:snow_bricks) instead of plain Snow Blocks, and contains a loot chest with early-game resources — including a chance at [](@firesreflamed:steel_ingot).

## Generation

| Property | Value |
|---|---|
| Dimension | Overworld |
| Biomes | Snowy biomes (tagged `has_structure/snow_brick_igloo`) |
| Structure Type | Jigsaw-based |

The Snow Brick Igloo generates in the same cold and snowy biomes where vanilla Igloos appear, such as Snowy Plains and Snowy Taiga.

## Loot Chest

The igloo contains a single chest with **3–6 random items** drawn from the following pool:

| Item | Weight | Quantity |
|---|---|---|
| Snowball | 8 | 4–8 |
| Bread | 8 | 1–3 |
| Leather Boots | 7 | 1 |
| [](@firesreflamed:steel_ingot) | 7 | 1–2 |
| Coal | 5 | 1–4 |
| Wooden Pickaxe | 4 | 1 |

<Callout variant="tip">The Snow Brick Igloo is an early-game source of [](@firesreflamed:steel_ingot) — you can find Steel here before you have the resources to smelt [](@firesreflamed:carbonized_iron) yourself.</Callout>

## Structure Blocks

The igloo is built primarily from:

- [](@firesreflamed:snow_bricks)
- [](@firesreflamed:snow_brick_slab)
- [](@firesreflamed:snow_brick_stairs)

All of these can be crafted from vanilla Snow Blocks, so you can repair or extend the igloo without needing to find another one.
