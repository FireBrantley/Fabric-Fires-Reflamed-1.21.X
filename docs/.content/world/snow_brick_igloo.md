# Snow Brick Igloo

A naturally-generated structure found in cold and snowy biomes, built using **Snow Bricks**.

## Generation

- **Biomes:** Any snowy biome.
- **Type:** Jigsaw-based structure.

## Loot

The Snow Brick Igloo contains a chest with various early-game items, including **Steel Ingots**, making it a valuable source of materials before you set up your own smelting chain.

| Item | Weight | Quantity |
|---|---|---|
| Snowball | 8 | 4–8 |
| Bread | 8 | 1–3 |
| Leather Boots | 7 | 1 |
| Steel Ingot | 7 | 1–2 |
| Coal | 5 | 1–4 |
| Wooden Pickaxe | 4 | 1 |
