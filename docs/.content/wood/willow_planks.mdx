# Willow Planks

Willow Planks are the processed wood material of the Willow tree set. They are the base for all crafted Willow wood items and follow the same recipes as their Oak equivalents.

<PrefabObtaining />

## Properties

| Property | Value |
|---|---|
| Hardness | 2.0 |
| Sounds | Wood |
| Flammable | Yes |
