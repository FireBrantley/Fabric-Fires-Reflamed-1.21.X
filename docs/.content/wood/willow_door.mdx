# Willow Door

The Willow Door is a Willow-wood variant of the vanilla wooden door, crafted from [](@firesreflamed:willow_planks). It functions identically to other wooden doors.

<PrefabObtaining />

## Properties

| Property | Value |
|---|---|
| Hardness | 3.0 |
| Sounds | Wood |
| Flammable | Yes |
| Opens by hand | Yes |

## Notes

Willow Doors can be opened by hand (right-click) or with a Redstone signal. They pair naturally with the [](@firesreflamed:willow_trapdoor) and [](@firesreflamed:willow_fence_gate) for a complete Willow-themed build.
