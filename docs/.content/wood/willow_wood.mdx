# Willow Wood

Willow Wood is the bark-on-all-sides variant of [](@firesreflamed:willow_log), crafted by combining four logs in a 2×2 pattern. It is purely decorative and yields [](@firesreflamed:willow_planks) when broken or crafted.

<PrefabObtaining />

## Properties

| Property | Value |
|---|---|
| Hardness | 2.0 |
| Sounds | Wood |
| Flammable | Yes |

## Crafting

Arrange 4 [](@firesreflamed:willow_log)s in a 2×2 grid to yield 3 Willow Wood blocks.

Using an axe on Willow Wood produces [](@firesreflamed:stripped_willow_wood).
