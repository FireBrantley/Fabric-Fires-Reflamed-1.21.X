# Stripped Willow Log

The Stripped Willow Log is produced by using an axe on a [](@firesreflamed:willow_log). It has the same properties as the regular log but with bark removed from the sides.

<PrefabObtaining />

## Properties

| Property | Value |
|---|---|
| Hardness | 2.0 |
| Sounds | Wood |
| Axis | Pillar (X/Y/Z) |
| Flammable | Yes |

## Obtaining

Right-click any [](@firesreflamed:willow_log) with an axe to strip it in place, consuming one durability from the axe.

Stripped Willow Logs are also used in the [](@firesreflamed:willow_hanging_sign) recipe as the frame material.
