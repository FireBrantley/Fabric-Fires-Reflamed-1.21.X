# Stripped Willow Wood

Stripped Willow Wood is produced by using an axe on [](@firesreflamed:willow_wood). It is the bark-on-all-sides stripped variant.

<PrefabObtaining />

## Properties

| Property | Value |
|---|---|
| Hardness | 2.0 |
| Sounds | Wood |
| Flammable | Yes |

## Obtaining

Right-click any [](@firesreflamed:willow_wood) block with an axe to strip it in place.
