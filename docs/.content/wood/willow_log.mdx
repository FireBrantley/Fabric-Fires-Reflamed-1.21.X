# Willow Log

The Willow Log is the trunk block of the Willow tree, a new tree type added by Fire's Reflamed. It generates naturally in the Overworld and behaves identically to vanilla log blocks.

<PrefabObtaining />

## Properties

| Property | Value |
|---|---|
| Hardness | 2.0 |
| Sounds | Wood |
| Axis | Pillar (X/Y/Z) |
| Flammable | Yes |

## Obtaining

Willow Logs are obtained by chopping down a naturally generated Willow tree or by growing one from a [](@firesreflamed:willow_sapling). Trees generate in the Overworld with a low frequency (roughly 1-in-4 chunk attempts where a sapling would survive).

Using an axe on a Willow Log produces a [](@firesreflamed:stripped_willow_log).
