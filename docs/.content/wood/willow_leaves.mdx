# Willow Leaves

Willow Leaves make up the canopy of the Willow tree. They drop [](@firesreflamed:willow_sapling) with a small chance, and [](@firesreflamed:hanging_willow_leaves) are generated beneath them naturally.

<PrefabObtaining />

## Properties

| Property | Value |
|---|---|
| Hardness | 0.2 |
| Sounds | Grass |
| Flammable | Yes |
| Transparent | Yes |

## Drops

- [](@firesreflamed:willow_sapling) — low chance when broken without shears
- [](@firesreflamed:hanging_willow_leaves) — low chance when broken without shears
- Sticks — occasional drop
- Themselves — when broken with shears
