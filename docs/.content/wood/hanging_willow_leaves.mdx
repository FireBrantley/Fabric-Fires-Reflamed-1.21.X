# Hanging Willow Leaves

Hanging Willow Leaves are a decorative block that generates on the underside of Willow trees, creating a weeping willow-like canopy effect. They have no collision and break instantly.

<PrefabObtaining />

## Properties

| Property | Value |
|---|---|
| Hardness | 0.0 (instant break) |
| Collision | None — players pass through |
| Sounds | Moss Carpet |
| Placement | Hangs from ceiling/underside of blocks |

## Obtaining

Hanging Willow Leaves generate naturally beneath [](@firesreflamed:willow_leaves) on Willow trees. They can also be collected using shears. Without shears, they drop nothing.

## Notes

Hanging Willow Leaves behave similarly to Vine or Spore Blossom — they are purely decorative, emit no light, and create no hitbox obstacle. Use them to add draping foliage to builds or re-create the weeping willow look indoors.
