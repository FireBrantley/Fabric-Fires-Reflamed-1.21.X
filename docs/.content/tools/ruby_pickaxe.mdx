# Ruby Pickaxe

The Ruby Pickaxe is a pickaxe crafted from [](@firesreflamed:ruby_gem). It shares similar stats with the [](@firesreflamed:steel_pickaxe) but with slightly less durability. Ruby has no armor set, making tools its primary use.

<PrefabObtaining />

## Stats

| Property | Value |
|---|---|
| Durability | 650 |
| Mining Speed | 6.0 |
| Mining Level | Iron-equivalent |
| Enchantability | 14 |
| Repair Item | [](@firesreflamed:ruby_gem) |

## Notes

Ruby Gems are refined from [](@firesreflamed:ruby_crystal) by crafting two crystals vertically or by smelting [](@firesreflamed:ruby_ore) directly. Ruby tools have the same mining level as Iron tools, but offer slightly more durability than Iron.
