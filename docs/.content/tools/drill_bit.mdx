# Drill Bit

The Drill Bit is an intermediate crafting component used to craft the [](@firesreflamed:drill). It is not a usable tool on its own.

<PrefabObtaining />

## Crafting

```
 N 
NIN
```
*(N = [](@firesreflamed:steel_nugget), I = [](@firesreflamed:steel_ingot))*

## Uses

Used exclusively as an ingredient in the [](@firesreflamed:drill) recipe.
