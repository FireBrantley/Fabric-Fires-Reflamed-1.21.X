# Steel Drill

The Drill is a unique area-mining tool that functions like a pickaxe but mines a **3×3 area** on the face you're looking at.

## Behavior

- Mines a 3×3 grid perpendicular to the face you hit.
- Works on any pickaxe-mineable block.
- Uses Steel tool material stats (durability 750, speed 6.0).

## Obtaining

Requires a **Drill Bit** made from steel nuggets and ingots, which is then combined with a Gold Block.
