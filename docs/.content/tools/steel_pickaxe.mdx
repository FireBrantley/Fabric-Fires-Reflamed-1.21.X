# Steel Pickaxe

The Steel Pickaxe is a mid-tier pickaxe crafted from [](@firesreflamed:steel_ingot). It outperforms Iron in both durability and mining speed and mines at Iron level.

<PrefabObtaining />

## Stats

| Property | Value |
|---|---|
| Durability | 750 |
| Mining Speed | 6.0 |
| Mining Level | Iron-equivalent |
| Enchantability | 14 |
| Repair Item | [](@firesreflamed:steel_ingot) |

> For comparison: Iron pickaxe has 250 durability and 6.0 speed.

## Notes

Steel tools are crafted — Steel has no natural ore, so you'll need to produce [](@firesreflamed:steel_ingot) by smelting [](@firesreflamed:carbonized_iron) first. See the [](@firesreflamed:steel_ingot) page for the full crafting chain.
