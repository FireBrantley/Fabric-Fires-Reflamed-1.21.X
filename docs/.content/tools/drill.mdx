# Drill

The Drill is a unique Steel-tier mining tool that breaks a **3×3 area** of blocks in a single swing, making it one of the most efficient tunneling tools in the mod. It is crafted from a [](@firesreflamed:drill_bit) and a Gold Block.

<PrefabObtaining />

## Crafting

The Drill requires two steps to craft. First, build a [](@firesreflamed:drill_bit):

```
 N 
NIN
```
*(N = Steel Nugget, I = Steel Ingot)*

Then assemble the Drill:

```
B  
 G 
```
*(B = Drill Bit, G = Gold Block)*

## Behavior

When you mine any block with the Drill, it breaks a **3×3 grid perpendicular to the face you hit** — effectively a full tunnel cross-section in one action. It works on any block that a pickaxe can mine.

| Property | Value |
|---|---|
| Mining Area | 3×3 |
| Durability | 750 |
| Mining Speed | 6.0 |
| Mining Level | Iron-equivalent |
| Repair Item | Steel Ingot |

The Drill uses the same material stats as [](@firesreflamed:steel_pickaxe) and can be repaired on an anvil with [](@firesreflamed:steel_ingot)s.
