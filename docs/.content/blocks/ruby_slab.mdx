# Ruby Slab

Ruby Slab is a decorative slab block crafted from [](@firesreflamed:ruby_bricks) or cut from [](@firesreflamed:block_of_ruby) in a stonecutter.

<PrefabObtaining />

## Properties

| Property | Value |
|---|---|
| Hardness | 4.0 |
| Required Tool | Pickaxe |
| Sounds | Amethyst |

## Obtaining

Craft 3 [](@firesreflamed:ruby_bricks) in a horizontal row to yield 6 Ruby Slabs, or use a stonecutter with [](@firesreflamed:ruby_bricks) or [](@firesreflamed:block_of_ruby) as input.
