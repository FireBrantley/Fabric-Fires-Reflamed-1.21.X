# Block of Steel

The Block of Steel is a compact storage block that holds 9 [](@firesreflamed:steel_ingot)s. It is also required as a crafting ingredient for the [](@firesreflamed:steel_bat).

<PrefabObtaining />

## Properties

| Property | Value |
|---|---|
| Hardness | 5.0 |
| Required Tool | Pickaxe |
| Sounds | Metal |

## Crafting

Arrange 9 [](@firesreflamed:steel_ingot)s in a 3×3 crafting grid to produce one Block of Steel. Placing the block alone in a crafting grid returns 9 ingots.

## Uses

- Compact storage for Steel Ingots
- Required ingredient in the [](@firesreflamed:steel_bat) recipe
