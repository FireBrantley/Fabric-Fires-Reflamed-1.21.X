# Snow Bricks

Snow Bricks are a decorative snow-themed building block crafted from vanilla Snow Blocks. They are the primary material used to construct the [](@firesreflamed:snow_brick_igloo) structure, and come with stair, slab, and wall variants.

<PrefabObtaining />

## Properties

| Property | Value |
|---|---|
| Hardness | 0.5 |
| Required Tool | Pickaxe or Shovel |
| Sounds | Snow |

## Crafting

Arrange 4 Snow Blocks in a 2×2 pattern to yield **4 Snow Bricks**.

## Stonecutter

Snow Blocks and Snow Bricks can both be converted to any Snow Brick variant using a stonecutter:

- [](@firesreflamed:snow_brick_stairs)
- [](@firesreflamed:snow_brick_slab)
- [](@firesreflamed:snow_brick_wall)
