# Ruby Wall

Ruby Wall is a decorative wall block crafted from [](@firesreflamed:ruby_bricks) or cut from [](@firesreflamed:block_of_ruby) in a stonecutter.

<PrefabObtaining />

## Properties

| Property | Value |
|---|---|
| Hardness | 4.0 |
| Required Tool | Pickaxe |
| Sounds | Amethyst |

## Obtaining

Craft 6 [](@firesreflamed:ruby_bricks) in two horizontal rows to yield 6 Ruby Walls, or use a stonecutter with [](@firesreflamed:ruby_bricks) or [](@firesreflamed:block_of_ruby) as input.
