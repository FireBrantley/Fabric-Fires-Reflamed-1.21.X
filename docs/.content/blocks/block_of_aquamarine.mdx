# Block of Aquamarine

The Block of Aquamarine is a compact storage block that holds 9 [](@firesreflamed:aquamarine_shard)s.

<PrefabObtaining />

## Properties

| Property | Value |
|---|---|
| Hardness | 4.0 |
| Required Tool | Pickaxe |
| Sounds | Amethyst Block |

## Crafting

Arrange 9 [](@firesreflamed:aquamarine_shard)s in a 3×3 crafting grid to produce one Block of Aquamarine. Placing the block alone in a crafting grid returns 9 shards.
