# Ruby Bricks

Ruby Bricks are a decorative building block crafted from [](@firesreflamed:block_of_ruby). They are the base of the Ruby decorative block set, with matching stair, slab, and wall variants.

<PrefabObtaining />

## Properties

| Property | Value |
|---|---|
| Hardness | 4.0 |
| Required Tool | Pickaxe |
| Sounds | Amethyst |

## Crafting

Arrange 4 [](@firesreflamed:block_of_ruby)s in a 2×2 pattern to yield **4 Ruby Bricks**.

## Stonecutter

Ruby Bricks and [](@firesreflamed:block_of_ruby) can both be converted to any variant in a stonecutter:

- [](@firesreflamed:ruby_brick_stairs)
- [](@firesreflamed:ruby_brick_slab)
- [](@firesreflamed:ruby_brick_wall)
