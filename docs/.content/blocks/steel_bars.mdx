# Steel Bars

Steel Bars are a decorative block crafted from [](@firesreflamed:steel_ingot)s, functioning identically to Iron Bars. They are useful for windows, cages, and security grilles in steel-themed builds.

<PrefabObtaining />

## Properties

| Property | Value |
|---|---|
| Hardness | 5.0 |
| Required Tool | Pickaxe |
| Sounds | Metal |

## Notes

Steel Bars connect to adjacent solid blocks and other bar blocks, creating grating patterns. They are non-opaque and do not block light. Pair with [](@firesreflamed:steel_chain) and [](@firesreflamed:steel_lantern) for a complete steel-themed aesthetic.
