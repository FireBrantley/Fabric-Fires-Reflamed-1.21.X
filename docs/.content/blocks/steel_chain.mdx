# Steel Chain

The Steel Chain is a decorative block crafted from [](@firesreflamed:steel_ingot)s, functioning identically to the vanilla Chain block. It can be used to hang lanterns or as a building element.

<PrefabObtaining />

## Properties

| Property | Value |
|---|---|
| Hardness | 5.0 |
| Required Tool | Pickaxe |
| Sounds | Chain |

## Crafting

```
I
I
I
```
*(I = Steel Ingot — 3 ingots, vertical, yields 1 Steel Chain)*

## Notes

Steel Chain behaves exactly like the vanilla Chain block — it is non-opaque, can be placed in any axis orientation, and connects visually to adjacent chains and lanterns. Use it with [](@firesreflamed:steel_lantern) for a cohesive steel-themed build.
