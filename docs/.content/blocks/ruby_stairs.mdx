# Ruby Stairs

Ruby Stairs are a decorative stair block crafted from [](@firesreflamed:ruby_bricks) or cut from [](@firesreflamed:block_of_ruby) in a stonecutter.

<PrefabObtaining />

## Properties

| Property | Value |
|---|---|
| Hardness | 4.0 |
| Required Tool | Pickaxe |
| Sounds | Amethyst |

## Obtaining

Craft 6 [](@firesreflamed:ruby_bricks) in the standard stair pattern, or use a stonecutter with [](@firesreflamed:ruby_bricks) or [](@firesreflamed:block_of_ruby) as input.
