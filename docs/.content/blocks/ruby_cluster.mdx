# Ruby Cluster

The Ruby Cluster is a decorative light-emitting block crafted from [](@firesreflamed:ruby_gem)s. It behaves similarly to an Amethyst Cluster — non-opaque, glowing, and placeable on most surfaces.

<PrefabObtaining />

## Properties

| Property | Value |
|---|---|
| Hardness | 1.0 |
| Light Level | 7 |
| Opaque | No |
| Required Tool | Pickaxe |
| Sounds | Amethyst Cluster |

## Crafting

```
 R 
RRR
```
*(R = Ruby Gem — 3 total, yields 1 Ruby Cluster)*

## Notes

The Ruby Cluster can be placed on any solid surface. Its light level of 7 is useful for subtle ambient lighting without fully illuminating an area. It does not prevent mob spawning on its own.
