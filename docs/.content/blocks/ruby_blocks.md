# Ruby Decorative Blocks

Ruby Gems can be used to craft a set of decorative building blocks. These can be crafted manually or converted using a **Stonecutter**.

### Ruby Cluster
Emits a light level of 7 and is non-opaque. It behaves similarly to an amethyst cluster.
