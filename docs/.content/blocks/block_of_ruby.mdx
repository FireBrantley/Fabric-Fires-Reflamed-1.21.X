# Block of Ruby

The Block of Ruby is a compact storage block that holds 9 [](@firesreflamed:ruby_gem)s. It is also used as a crafting ingredient for the [](@firesreflamed:ruby_bat) and is the base material for all Ruby decorative blocks.

<PrefabObtaining />

## Properties

| Property | Value |
|---|---|
| Hardness | 4.0 |
| Required Tool | Pickaxe |
| Sounds | Amethyst Block |

## Crafting

Arrange 9 [](@firesreflamed:ruby_gem)s in a 3×3 crafting grid to produce one Block of Ruby. Placing the block alone in a crafting grid returns 9 gems.

## Stonecutter

The Block of Ruby can be converted into any Ruby decorative block variant using a stonecutter:

- [](@firesreflamed:ruby_bricks)
- [](@firesreflamed:ruby_brick_stairs)
- [](@firesreflamed:ruby_brick_slab)
- [](@firesreflamed:ruby_brick_wall)

## Uses

- Compact storage for Ruby Gems
- Required ingredient in the [](@firesreflamed:ruby_bat) recipe
- Source material for all Ruby decorative blocks
