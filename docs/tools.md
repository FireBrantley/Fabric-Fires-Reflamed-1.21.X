# Tools

Fire's Reflamed adds three complete tool sets (Titanium, Steel, Ruby) plus a unique mining tool: the **Drill**.

All tool sets include a Pickaxe, Shovel, Axe, Hoe, and Sword (swords are listed on the [Weapons](weapons) page).

---

## Tool Material Stats

| Material | Durability | Mining Speed | Attack Damage Bonus | Enchantability | Repair Item | Mining Level |
|---|---|---|---|---|---|---|
| **Titanium** | 2,500 | 13.0 | 10.0 | 28 | Titanium Ingot | Diamond-equivalent |
| **Steel** | 750 | 6.0 | 10.0 | 14 | Steel Ingot | Iron-equivalent |
| **Ruby** | 650 | 6.0 | 10.0 | 14 | Ruby Gem | Iron-equivalent |

> For comparison: Iron has 250 durability and 6.0 speed; Diamond has 1,561 durability and 8.0 speed.

## Titanium Tools

Titanium is the top-tier tool material in the mod. It mines at diamond level and has exceptional durability and enchantability.

**Crafting** (standard vanilla patterns using Titanium Ingots + Sticks):

| Tool | Recipe |
|---|---|
| Titanium Pickaxe | `III / _S_ / _S_` |
| Titanium Shovel | `_I_ / _S_ / _S_` |
| Titanium Axe | `II_ / IS_ / _S_` (or mirrored) |
| Titanium Hoe | `II_ / _S_ / _S_` (or mirrored) |

## Drill

The Drill is a unique area-mining tool made from Steel. It functions like a pickaxe but mines a **3×3 area** on the face you're looking at, making it extremely efficient for tunneling.

**Ingredients:**
1. Craft a **Drill Bit** first:
   - ` N ` / `NIN` (N = Steel Nugget, I = Steel Ingot)
2. Craft the **Drill**:
   - `B  ` / ` G ` (B = Drill Bit, G = Gold Block)

**Behavior:**
- Mines a 3×3 grid perpendicular to the face you hit
- Works on any pickaxe-mineable block
- Uses Steel tool material stats (durability 750, speed 6.0)
- Repair with Steel Ingots
