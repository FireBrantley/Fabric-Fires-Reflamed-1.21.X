# Structures

Fire's Reflamed adds one new naturally-generated structure to the Overworld.

---

## Snow Brick Igloo

A variant of the vanilla igloo built using **Snow Bricks** instead of plain snow. It generates in cold/snowy biomes.

**Generation:**
- Biomes: Snowy biomes (tagged with `has_structure/snow_brick_igloo`)
- Structure type: Jigsaw-based

**Loot Chest Contents:**

The Snow Brick Igloo contains a chest with 3–6 random items drawn from the following pool:

| Item | Weight | Quantity |
|---|---|---|
| Snowball | 8 | 4–8 |
| Bread | 8 | 1–3 |
| Leather Boots | 7 | 1 |
| Steel Ingot | 7 | 1–2 |
| Coal | 5 | 1–4 |
| Wooden Pickaxe | 4 | 1 |

> The Steel Ingot loot makes the Snow Brick Igloo an early-game source of Steel, before you've set up a smelting chain.
