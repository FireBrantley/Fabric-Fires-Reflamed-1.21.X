# Willow Wood

The **Willow** is a new tree type added by Fire's Reflamed. It generates naturally in the Overworld and provides a complete wood set matching vanilla wood functionality.

---

## Obtaining Willow Wood

Willow trees generate naturally in the Overworld with a low chance (roughly 1-in-4 chunk attempts to add an extra willow tree, wherever a willow sapling would survive). They can also be grown from **Willow Saplings**.

---

## Willow Tree Components

| Block | Notes |
|---|---|
| Willow Log | Pillar block, same hardness as Oak Log |
| Willow Wood | Pillar block (log with bark on all sides) |
| Stripped Willow Log | Produced by using an axe on Willow Log |
| Stripped Willow Wood | Produced by using an axe on Willow Wood |
| Willow Leaves | Standard leaf block |
| Hanging Willow Leaves | Decorative hanging moss-like block; no collision, breaks instantly |
| Willow Sapling | Can be planted to grow a new Willow tree |

## Willow Planks & Crafted Items

All willow wood items follow the same crafting patterns as their oak equivalents.

| Item/Block | Recipe |
|---|---|
| Willow Planks (×4) | Any Willow Log (shapeless) |
| Willow Stairs | Standard stair pattern from Willow Planks |
| Willow Slab | Standard slab pattern from Willow Planks |
| Willow Fence | Standard fence pattern from Willow Planks |
| Willow Fence Gate | Standard fence gate pattern from Willow Planks |
| Willow Door | Standard door pattern from Willow Planks |
| Willow Trapdoor | Standard trapdoor pattern from Willow Planks |
| Willow Pressure Plate | 2 Willow Planks (horizontal) |
| Willow Button | 1 Willow Plank (shapeless) |
| Willow Sign (×3) | `WWW / WWW / _S_` (W=Willow Planks, S=Stick) |
| Willow Hanging Sign (×6) | `C_C / WWW / WWW` (C=Chain, W=Stripped Willow Log) |
| Willow Boat | `P_P / PPP` (P=Willow Planks) |
| Willow Chest Boat | Willow Boat + Chest (shapeless) |

## Hanging Willow Leaves

A decorative block that hangs downward, similar to vine or spore blossom behavior.

- **No collision** — players can walk through it
- **Breaks instantly** — no tool needed
- **Sound:** Moss Carpet
- Can be placed hanging from other blocks (ceiling/underside placement)
