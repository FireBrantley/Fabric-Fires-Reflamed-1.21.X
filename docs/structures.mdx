# Structures

Fire's Reflamed adds one new naturally generated structure to the Overworld.

---

## Snow Brick Igloo

The [](@firesreflamed:snow_brick_igloo) is a variant of the vanilla Igloo built from [](@firesreflamed:snow_bricks) instead of plain Snow Blocks. It generates in cold and snowy biomes and contains a loot chest with early-game resources — including a chance at [](@firesreflamed:steel_ingot), making it a useful early source of Steel before you've set up a smelting chain.

### Loot

| Item | Weight | Quantity |
|---|---|---|
| Snowball | 8 | 4–8 |
| Bread | 8 | 1–3 |
| Leather Boots | 7 | 1 |
| [](@firesreflamed:steel_ingot) | 7 | 1–2 |
| Coal | 5 | 1–4 |
| Wooden Pickaxe | 4 | 1 |

### Building Blocks

The igloo is built from [](@firesreflamed:snow_bricks), [](@firesreflamed:snow_brick_slab), and [](@firesreflamed:snow_brick_stairs) — all of which you can craft yourself from vanilla Snow Blocks, so you can repair or extend the structure freely.
